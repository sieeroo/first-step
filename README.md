# Anything 4U Pay - Simple E-Wallet Simulation

Ini adalah program pertama yang saya buat sebagai mahasiswa Informatika. Program ini mensimulasikan sistem pembayaran digital (e-wallet) sederhana berbasis terminal menggunakan bahasa C.

## Fitur
* **Registrasi Nama:** Input nama pengguna di awal program.
* **Top Up:** Menambah saldo ke dalam sistem.
* **Transfer:** Mengirim saldo ke pengguna lain dengan validasi (cek apakah saldo cukup).
* **Looping Transaksi:** Pengguna bisa melakukan transaksi berulang kali tanpa harus merestart program.

## Teknologi yang Digunakan
* **Bahasa Pemrograman:** C
* **Konsep CS:** Variable declaration, Scanf/Printf, Do-While Loop, Switch Case, dan If-Else Condition.

## Cara Menjalankan
1. Install compiler C (seperti gcc) di komputer/laptop.
2. Clone repository ini:
   ```bash
   git clone https://github.com/sieeroo/first-step.git
3. Compile program
   ```bash
   gcc simple-ewallet-cli.c -o simple-ewallet-cli
4. Jalankan program
   ```bash
   ./simple-ewallet-cli
